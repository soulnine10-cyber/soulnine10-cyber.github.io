1. YouTube API 서비스 사용

이 프로그램은 YouTube API 서비스를 사용합니다. 이 프로그램을 사용하면 YouTube 서비스 약관에 따르기로 동의하는 것이며, Google 개인정보처리방침(http://www.google.com/policies/privacy)이 적용됩니다.

2. 접근하는 정보 (YouTube API 데이터)

  • 연결한 본인 YouTube 채널의 이름·ID와 채널 상태(긴 영상을 올릴 수 있는지).
  • 본인 채널의 재생목록 이름·ID (영상을 넣을 재생목록을 고르거나 새로 만들 때).
  • 이 프로그램이 올린 영상의 영상 ID와 공개 범위 (올리기·공개 범위 변경의 결과로 받음).
  • 사용하는 권한(OAuth 범위): youtube.upload(영상 업로드), youtube(썸네일 설정·재생목록 관리·공개 범위 변경).
  • 다른 사용자나 다른 채널의 정보, 댓글, 구독, 시청 기록, 통계는 접근하지 않습니다.

3. 정보를 쓰는 방법과 공유

  • 회사가 직접 만든 영상 파일을 본인 채널에 올리고 제목·설명·해시태그·썸네일·재생목록·공개 범위를 정하는 데에만 씁니다.
  • 받은 정보는 운영자(채널 소유자) 본인만 프로그램 화면에서 봅니다. 회사 안팎의 다른 사람이나 서비스와 공유하거나 판매하지 않으며, 광고·분석에 쓰지 않습니다.
  • 이 프로그램은 제3자 콘텐츠나 광고를 보여 주지 않습니다.

4. 저장하는 정보, 저장 위치, 보관 기간

  • 저장하는 것: Google 인증 토큰 1개, 채널 이름·ID와 채널 상태, 고른 재생목록(이름·ID), 올린 기록.
  • 올린 기록에는 회사 파일 이름, 회사가 정한 제목·해시태그·공개 범위, 올린 시각, 그리고 YouTube가 돌려준 영상 ID·주소가 들어갑니다.
  • 모두 운영자 본인의 컴퓨터(사용자 기기) 안에 파일로만 저장되며, YouTube에서 받은 정보는 Google 외 다른 서버로 보내지 않습니다.
  • 보관 기간: 연결되어 있는 동안 채널 정보는 하루에 한 번 YouTube에서 다시 받아 갱신하고(이때 접근 권한이 살아 있는지도 확인합니다), 고른 재생목록은 30일이 되기 전에 다시 받아 갱신합니다. 갱신하지 못한 정보는 받은 지 30일이 지나면 자동으로 지웁니다.
  • 올린 영상의 영상 ID·주소는 올린 날부터 30일이 지나면 자동으로 지웁니다. 회사 파일 이름·제목·올린 시각은 같은 영상을 두 번 올리지 않도록 남겨 둡니다.
  • 이 프로그램과 이 안내 페이지는 쿠키나 그와 비슷한 추적 기술을 쓰지 않습니다.

5. 삭제와 접근 취소

  • 프로그램의 [연결 끊기]를 누르면 Google에 토큰 취소를 바로 요청하고, 저장된 토큰과 YouTube에서 받은 정보(채널 정보, 영상 ID·주소, 고른 재생목록)를 바로 지웁니다.
  • Google 계정 보안 설정(https://security.google.com/settings/security/permissions)에서 언제든지 이 프로그램의 접근 권한을 취소할 수 있습니다. 프로그램은 실행 중 연결 상태를 하루에 한 번 이상 확인하며, 취소된 것을 확인하면 YouTube에서 받은 정보를 바로 지웁니다. 이와 별개로 위의 30일 보관 기한은 늘 적용됩니다.
  • 아래 문의 메일로 삭제를 요청하면 저장된 정보를 7일 안에 지웁니다.
  • 이 프로그램에서 지워도 YouTube에 올라간 영상과 YouTube에 저장된 정보는 지워지지 않습니다. 그것은 YouTube 스튜디오에서 직접 관리합니다.

Privacy Policy (English)

1. Use of YouTube API Services

This application uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service, and the Google Privacy Policy (http://www.google.com/policies/privacy) applies.

2. Data accessed (YouTube API Data)

  • The name, ID and status (whether long uploads are allowed) of the user's own YouTube channel that is connected.
  • The names and IDs of the channel's own playlists (to choose or create a playlist for new videos).
  • The video ID and privacy status of videos uploaded by this application (returned as the result of an upload or a privacy change).
  • OAuth scopes used: youtube.upload (upload videos) and youtube (set thumbnails, manage playlists, change privacy status).
  • No data of other users or channels, and no comments, subscriptions, watch history or statistics, are accessed.

3. How data is used and shared

  • Data is used only to upload the company's own video files to the user's own channel and to set their title, description, hashtags, thumbnail, playlist and privacy status.
  • Only the operator (the channel owner) sees this data, in the application's own screen. It is not shared with or sold to any other person or service, inside or outside the company, and is not used for advertising or analytics.
  • The application does not display third-party content or advertisements.

4. Data stored, where, and for how long

  • Stored: one Google OAuth token, the channel name, ID and status, the chosen playlist (name and ID) and an upload log.
  • The upload log contains the company's file names, the title, hashtags and privacy setting chosen by the company, the upload time, and the video ID and URL returned by YouTube.
  • Everything is stored only as files on the operator's own computer (the user's device). Data received from YouTube is never sent to any server other than Google's.
  • Retention: while connected, the channel information is refreshed from YouTube once a day (which also confirms that the authorization is still valid), and the chosen playlist is refreshed before it is 30 days old. Any information that could not be refreshed is deleted automatically 30 days after it was received.
  • Video IDs and URLs of uploaded videos are deleted automatically 30 days after upload. The company's own file name, title and upload time are kept so that the same video is not uploaded twice.
  • Neither the application nor this page uses cookies or similar tracking technologies.

5. Deletion and revoking access

  • Choosing "Disconnect" in the application immediately asks Google to revoke the token and immediately deletes the stored token and the data received from YouTube (channel information, video IDs and URLs, chosen playlist).
  • You can revoke this application's access at any time via the Google security settings page (https://security.google.com/settings/security/permissions). While running, the application checks its authorization at least once a day and deletes the data received from YouTube as soon as it detects the revocation. The 30-day retention limit above always applies as well.
  • If you request deletion by email (below), the stored data is deleted within 7 days.
  • Deleting data in this application does not delete videos or other data stored on YouTube. Those are managed directly in YouTube Studio.

6. Changes

Changes to this policy will be posted on this page with the date.
