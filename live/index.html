이 프로그램은 무엇인가요?

  • sb컴퍼니가 자사 유튜브 채널 「모던스톡」의 주식 시황 라이브 방송을 켜고 끄기 위해 회사 안에서만 쓰는 도구입니다.
  • 외부에 배포하거나 판매하지 않으며, 사용자는 채널 소유자(운영자) 1명입니다.
  • 운영자의 컴퓨터에서 실행됩니다. 운영자가 자기 디스코드 서버의 채널에 명령을 쓰면, YouTube API 서비스(YouTube Data API)로 YouTube와 통신하고 같은 컴퓨터의 방송 프로그램(OBS)을 조작합니다.
  • 명령은 미리 허용해 둔 운영자 계정만 내릴 수 있습니다.

하는 일

  • 운영자가 정한 제목·설명·공개 범위로 본인 채널에 라이브 방송을 만들고, OBS 송출(스트림)과 연결합니다.
  • 운영자가 정한 문구로 이 컴퓨터에서 만든 그림을 방송 썸네일로 설정합니다.
  • 본인 채널의 최근 방송 목록(최대 10개)을 보여 주고, 방송을 시작·종료하며, 필요 없는 방송을 지웁니다.
  • 방송 시작·종료는 운영자가 명령하거나 승인했을 때만 합니다. 단, 매일 15:40(한국 시간)에는 진행 중인 방송을 자동으로 종료합니다.
  • AI 도우미(Anthropic의 Claude)가 운영자의 말을 알아듣고 위 명령을 실행합니다.
  • 하지 않는 일: 다른 사용자·채널의 데이터 접근, 댓글·채팅·구독·시청 기록·통계 접근, 스트림 키 읽기, 데이터 판매·공유·광고 활용.

What is this?

  • Jarvis Live is an internal tool used only by SB Company to start and end the stock-market live streams on its own YouTube channel.
  • It is not distributed to or usable by anyone else. Its only user is the channel owner (one operator).
  • It runs on the operator's own computer. When the operator types a command in a channel on the operator's own Discord server, it communicates with YouTube through YouTube API Services (YouTube Data API) and controls the broadcasting software (OBS) on the same computer.
  • Only the operator's pre-approved account can give commands.
  • What it does: creates a live broadcast on the operator's own channel with the title, description and privacy status chosen by the operator and binds it to the OBS stream; sets a thumbnail image made on the operator's computer from text chosen by the operator; lists the channel's recent broadcasts (up to 10); starts, ends and deletes broadcasts. Broadcasts are started or ended only when the operator commands or approves it, except that any broadcast still live at 15:40 (Korea time) is ended automatically every day. An AI assistant (Claude by Anthropic) interprets the operator's messages and runs these commands.
  • What it does not do: access any other user's or channel's data; access comments, live chat, subscriptions, watch history or statistics; read stream keys; or sell, share or use data for advertising.
