1. YouTube API 서비스 사용

이 프로그램은 YouTube API 서비스를 사용합니다. 이 프로그램을 사용하면 YouTube 서비스 약관에 따르기로 동의하는 것이며, Google 개인정보처리방침(http://www.google.com/policies/privacy)이 적용됩니다.

2. 접근하는 정보 (YouTube API 데이터)

  • 연결한 본인 채널의 라이브 방송 정보: 방송 ID, 제목, 설명, 예약 시각, 공개 범위, 방송 상태(예정·진행 중·종료), 연결된 스트림 ID.
  • 본인 채널의 스트림(송출 설정) ID와 상태. 스트림 키는 요청하지 않습니다.
  • 사용하는 권한(OAuth 범위): youtube(라이브 방송 만들기·시작·종료·삭제, 썸네일 설정).
  • 다른 사용자나 다른 채널의 정보, 댓글, 채팅, 구독, 시청 기록, 통계는 접근하지 않습니다.

3. 정보를 쓰는 방법과 공유

  • 운영자의 명령대로 본인 채널의 라이브 방송을 만들고 시작·종료하며, 그 결과를 운영자에게 알리는 데에만 씁니다.
  • 운영자가 직접 승인해 쓰는 아래 두 서비스에만 필요한 만큼 전달합니다. 그 밖에 회사 안팎의 다른 사람이나 서비스와 공유하거나 판매하지 않으며, 광고·분석에 쓰지 않습니다.
  • Discord: 운영자가 명령을 내리고 결과를 보는 창구입니다. 결과(방송 ID·제목·상태·방송 주소)가 운영자의 디스코드 서버 채널에 봇 메시지로 표시됩니다. (Discord 개인정보처리방침)
  • Anthropic (Claude): 운영자의 말을 알아듣고 명령을 실행하는 AI 도우미입니다. 운영자가 쓴 문장과 도구 실행 결과(방송 ID·제목·상태)를 운영자의 명령을 처리하기 위해서만 보냅니다. (Anthropic 개인정보처리방침)
  • 이 프로그램은 제3자 콘텐츠나 광고를 보여 주지 않습니다.

4. 저장하는 정보, 저장 위치, 보관 기간

  • 저장하는 것: Google 인증 토큰 1개, 실행 기록(방송 ID·제목이 들어갈 수 있음), 방송 썸네일 그림(파일 이름이 방송 ID), 디스코드 채널의 봇 메시지, AI 도우미와 나눈 대화 기록.
  • 디스코드 메시지는 Discord에, 나머지는 모두 운영자 본인의 컴퓨터 안에 파일로 저장됩니다. 인증 토큰은 운영자의 컴퓨터 밖으로 보내지 않습니다.
  • 보관 기간: 실행 기록, 썸네일 그림, 디스코드 채널의 봇 메시지는 하루에 한 번 확인해 29일이 지난 것을 자동으로 지웁니다.
  • AI 도우미와의 대화는 날짜가 바뀌면 새로 시작하며, 운영자의 컴퓨터에 남은 대화 기록은 자동 정리 기능으로 30일이 지나면 지워집니다.
  • 이 프로그램과 이 안내 페이지는 쿠키나 그와 비슷한 추적 기술을 쓰지 않습니다.

5. 삭제와 접근 취소

  • Google 계정 보안 설정(https://security.google.com/settings/security/permissions)에서 언제든지 이 프로그램의 접근 권한을 취소할 수 있습니다. 취소하면 저장된 토큰은 더 이상 쓸 수 없게 되고, YouTube에서 받은 정보는 위의 보관 기한에 따라 30일 안에 모두 지워집니다.
  • 아래 문의 메일로 삭제를 요청하면 저장된 정보를 7일 안에 지웁니다.
  • 이 프로그램에서 지워도 YouTube에 저장된 방송과 정보는 지워지지 않습니다. 그것은 YouTube 스튜디오에서 직접 관리합니다.

Privacy Policy (English)

1. Use of YouTube API Services

This application uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service, and the Google Privacy Policy (http://www.google.com/policies/privacy) applies.

2. Data accessed (YouTube API Data)

  • Live broadcast information of the user's own connected channel: broadcast ID, title, description, scheduled start time, privacy status, life-cycle status (upcoming, live, complete) and the bound stream ID.
  • The ID and status of the channel's own streams (ingestion settings). Stream keys are not requested.
  • OAuth scope used: youtube (create, start, end and delete live broadcasts; set thumbnails).
  • No data of other users or channels, and no comments, live chat, subscriptions, watch history or statistics, are accessed.

3. How data is used and shared

  • Data is used only to create, start and end live broadcasts on the user's own channel as the operator commands, and to report the results to the operator.
  • Data is passed, only as needed, to the two services below, which the operator has expressly approved and uses directly. It is not shared with or sold to any other person or service, inside or outside the company, and is not used for advertising or analytics.
  • Discord: the channel through which the operator gives commands and sees results. Results (broadcast ID, title, status and broadcast URL) are shown as bot messages in a channel on the operator's own Discord server. (Discord Privacy Policy)
  • Anthropic (Claude): the AI assistant that interprets the operator's messages and runs the commands. The operator's messages and the tool results (broadcast ID, title and status) are sent to it only to process the operator's commands. (Anthropic Privacy Policy)
  • The application does not display third-party content or advertisements.

4. Data stored, where, and for how long

  • Stored: one Google OAuth token, a run log (which may contain broadcast IDs and titles), thumbnail images (file names are broadcast IDs), the bot's messages in the Discord channel, and the conversation records with the AI assistant.
  • Discord messages are stored on Discord; everything else is stored only as files on the operator's own computer. The OAuth token is never sent outside the operator's computer.
  • Retention: the run log, thumbnail images and the bot's messages in the Discord channel are checked once a day, and anything older than 29 days is deleted automatically.
  • Conversations with the AI assistant start fresh every day, and the conversation records left on the operator's computer are deleted by an automatic cleanup after 30 days.
  • Neither the application nor this page uses cookies or similar tracking technologies.

5. Deletion and revoking access

  • You can revoke this application's access at any time via the Google security settings page (https://security.google.com/settings/security/permissions). After revocation the stored token can no longer be used, and all data received from YouTube is deleted within 30 days under the retention rules above.
  • If you request deletion by email (below), the stored data is deleted within 7 days.
  • Deleting data in this application does not delete broadcasts or other data stored on YouTube. Those are managed directly in YouTube Studio.

6. Changes

Changes to this policy will be posted on this page with the date.
