이 프로그램은 무엇인가요?

  • sb컴퍼니가 매일 자체 제작하는 주식 시황 영상(세로 쇼츠·가로 영상)을 자사 유튜브 채널 「모던스톡」에 올리기 위해 회사 안에서만 쓰는 도구입니다.
  • 외부에 배포하거나 판매하지 않으며, 사용자는 채널 소유자(운영자) 1명입니다.
  • 운영자의 컴퓨터에서 실행되고, YouTube API 서비스(YouTube Data API)를 통해 YouTube와 통신합니다.

하는 일

  • 회사가 만든 영상 파일을 YouTube 채널에 업로드하고 제목·설명·해시태그를 넣습니다.
  • 썸네일을 설정하고 재생목록에 추가합니다.
  • 올린 영상의 처리 상태를 확인하고 공개 범위(비공개 ↔ 공개)를 바꿉니다.
  • 하지 않는 일: 다른 사용자·채널의 데이터 접근, 댓글·구독·시청 기록 접근, 데이터 판매·공유·광고 활용.

What is this?

  • Jarvis is an internal tool used only by SB Company to upload the stock-market videos it produces every day (vertical Shorts and horizontal videos) to its own YouTube channel.
  • It is not distributed to or usable by anyone else. Its only user is the channel owner (one operator).
  • It runs on the operator's own computer and communicates with YouTube through YouTube API Services (YouTube Data API).
  • What it does: uploads the company's own video files with title, description and hashtags; sets thumbnails; adds videos to playlists; checks processing status and changes privacy status (private ↔ public).
  • What it does not do: access any other user's or channel's data, access comments, subscriptions or watch history, or sell, share or use data for advertising.
